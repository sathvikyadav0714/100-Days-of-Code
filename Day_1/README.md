## Day 01 — Band Name Generator

### What I Learned

### Project

**Band Name Generator**

A simple Python program that asks the user for their **city name** and **pet name**, combines them, and generates a band name.

### Example

City: Hyderabad  
Pet: Bruno

Band Name: Hyderabad Bruno
